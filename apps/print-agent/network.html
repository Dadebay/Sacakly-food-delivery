Подключение чековых аппаратов

Интернет через Wi-Fi, печать — по кабелю через switch. Здесь можно проверить связь и добавить компьютеру адрес для второй сети аппаратов.

1. Проверить связь

По одному адресу в строке. Без указанного порта используется 9100. После попытки печати список подставляется из последнего задания — обновите это окно.

2. Настроить кабельное подключение

Настройки компьютера ещё не проверены.

Используйте маску из настроек аппаратов. Агент проверит их присутствие на кабеле, проверит дополнительный IP через ARP и сохранит результат для отката. Исходные адреса, DHCP, шлюзы и DNS сохраняются.

Автоматическая настройка доступна для Ethernet со статическим IP без шлюза. Она не перенастраивает Wi-Fi, роутер или аппараты. ARP проверяет занятые адреса среди включённых устройств; выбранный адрес следует исключить из DHCP-пула, если в этой сети есть DHCP-сервер.
Для настройки и отката появится системный запрос прав администратора. Если связь после добавления адреса не появится, агент удалит добавленные адреса.
