# Подключение кафе: Dev Notes — 2026-10-06

http://127.0.0.1:5174 — кабинет кафе и OWNER; http://127.0.0.1:3000/ru — витрина.
Отдельного опубликованного стенда пока нет. Локальное окружение запускается
по инструкции [PLAYWRIGHT_E2E.md](PLAYWRIGHT_E2E.md).

Проверить:
- OWNER создаёт скрытое кафе, выбирает до четырёх типов кухни и подключает ADMIN по телефону после его SMS-регистрации.
- ADMIN видит только назначенные кафе. До публикации заполняет филиал, раздел меню, блюдо и настройки принтера.
- Проверочный список показывает недостающие шаги. Включение ORDERING без обязательных данных возвращает 409; готовое кафе появляется на витрине.
- После публикации нельзя удалить последнего администратора, последний филиал, последнюю кухню или последнее доступное блюдо. Два одновременных закрытия последних филиалов оставляют один активный.
- Суши, бургеры, фастфуд и остальные типы фильтруются сервером; подписи доступны на tk/ru/en.
- ADMIN и ACCOUNTANT видят отчёт своего кафе. OPERATOR и чужое кафе получают 403. Период 1–93 дня определяется в часовом поясе Ашхабада, включая границы полуночи.
- На desktop и ширине 390 × 844 доступны формы, выбор кафе и прокручиваемые вкладки; нет горизонтального переполнения страницы. Проверить фокус с клавиатуры.
- Физическую печать проверить отдельно по [CAFE_ONBOARDING.md](CAFE_ONBOARDING.md).

## Автоматическая проверка

Результаты финального прогона записаны в [CHANGELOG.md](CHANGELOG.md).
API-тесты проверяют разрешённые/запрещённые роли, чужие идентификаторы,
конфликты версий, публикацию, конкурентное закрытие филиалов, суммы и границы
даты отчёта. Playwright проходит реальный путь создания/публикации кафе,
оформления заказа, выбора доставки и очереди чеков.

Тест сохраняет `owner-mobile.png` и `merchant-mobile.png` в игнорируемой
папке `test-results/`. Проверка циклов импортов охватывает TypeScript-модули
web и merchant. Новых библиотек не добавлено.

Известные сообщения браузера отмечаются в отчёте теста отдельно: Firefox
предупреждает о localhost bounce tracking и предзагрузке Next dev; WebKit
выводит ожидаемый 403 при проверке OWNER-доступа обычного сотрудника. Только
эти конкретные сообщения допускаются; runtime, hydration и остальные ошибки
приложения приводят к падению теста.

## Ограничения

Playwright Chromium, Firefox и WebKit не заменяют приёмку установленного
Chrome/Safari на реальных телефонах. Firebase работает в тестах через
недоставляющий провайдер; реальное получение push и бумажные чеки здесь
не проверяются. Отчёт не рассчитывает комиссию, выплаты или налоги.
Остальные ограничения запуска сохраняются в [ROADMAP.md](ROADMAP.md).
