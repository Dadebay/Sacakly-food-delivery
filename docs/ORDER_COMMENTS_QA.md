# Комментарий к заказу и поля чека — 2026-09-05

Стенд: `http://127.0.0.1:4008/orders` — временная production-сборка админки
с настоящим NestJS API, изолированной `alofood_test` и Redis DB 15.
Проверка выполнена на отдельной релизной ветке от актуального `main`.
Production выпускается через штатный GitHub Actions/VDS процесс.

Проверить:
- «Заказ по звонку» → «Комментарий к заказу»: сохранить многострочный текст,
  проверить его в карточке перед сборкой, таблице и подробностях заказа.
- «Изменить заказ»: заменить или очистить комментарий до передачи курьеру.
  После изменения запросить новый чек кнопкой печати.
- Проверить отсутствие комментария, пробелы, кириллицу, переносы строк,
  длинное слово и границу 500 символов. API отклоняет 501 символ и неверный тип.
- В основном и кухонном чеке комментарий расположен перед позициями;
  каждая введённая строка сохраняется. Старые задания очереди сохраняют исходный
  снимок, намеренная повторная печать получает актуальный комментарий.
- Верх чека короче на 60 точек (около 7,5 мм при 203 dpi), нижнее свободное
  поле для отрыва сохранено: минимум 120 точек (15 мм) до финальной подачи.
- Проверить desktop/mobile; пустой комментарий не занимает отдельный блок,
  длинный текст не обрезается и не расширяет страницу.
